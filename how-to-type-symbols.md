# Statistics Notation Reference

| Symbol | Meaning |
|--------|---------|
| $\bar{x}$ | x-bar or sample mean |
| $\mu$ | mu or population mean |
| $\sigma$ | sigma or population standard deviation |
| $\sigma^2$ | sigma squared or population variance |
| $\sum$ | sum of |
| $\sqrt{x}$ | square root of x |
| $\leq$ | less than or equal to |
| $\geq$ | greater than or equal to |
| $\approx$ | approximately equal to |
| $P(A)$ | probability of A |
| $P(A\|B)$ | probability of A given B |
| $P(A\cap B)$ | probability of A and B |
| $P(A\cup B)$ | probability of A or B |
| $H_0$ | null hypothesis |
| $H_a$ | alternative hypothesis |
| $\alpha$ | alpha / significance level |
| $\beta$ | beta |
| $R^2$ | R-squared |
| $\hat{y}$ | y-hat / predicted y |
| $\pm$ | plus or minus |
